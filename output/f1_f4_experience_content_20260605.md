## F1 新手教程

### 流程
```
1. 身份揭示（3秒）— "你是【港区警探 Inspector】"
2. 基础移动（15秒）— WASD/方向键 + 鼠标点击任务站
3. 任务教程（30秒）— 完成 1 个简单任务 (Tap/Sort)
4. 发现尸体（15秒）— 报案流程 + 紧急铃位置
5. 会议教程（30秒）— 投票/跳过/推理说明
6. 结果揭示（10秒）— 胜负条件说明
```

### 实现
- TutorialManager.cs 已有框架，联机流程已接入（M9.1）
- 增加"跳过教程"按钮和主菜单"重看教程"入口
- 教程中不暴露隐藏身份细节（不教怎么杀人不教怎么破坏）

## F2 设置和本地化

### 设置持久化
- 音量（主/音效/BGM 三轨）
- 窗口模式（全屏/窗口/无边框）

## F3 房间和聊天

### 房间流程
```
创建房间 → 生成房间码 → 等待玩家 → 全员准备 → 开始
加入房间 → 输入房间码 → 等待 → 准备 → 开始
```
- 房间码可一键复制
- 房主可踢人、设置规则（地图/人数/角色揭示）
- 准备/取消准备按钮
- 离房确认："确定离开？进度将丢失"

### 聊天频道
| 频道 | 谁可见 | 何时可用 |
|------|--------|---------|
| Meeting | 全体存活者 | 会议阶段 |
| Global | 全体存活者 | 行动阶段 |
| Proximity | 最近 3 格内玩家 | 行动阶段 |
| Ghost | 已出局玩家 | 任意阶段 |

- 消息长度限制：256 字符
- 发言冷却：5 秒
- 死亡玩家不能使用 Meeting/Global/Proximity 频道
- 间谍/内鬼可查看所有频道但不能发 Proximity

## F4 可访问性

### 色盲支持
- 关键状态使用文字标签辅助颜色：
  - 警察阵营 → "警蓝" 标签
  - 黑帮阵营 → "匪红" 标签
  - 破坏状态 → "⚡停电"/"🔒封锁"/"📡断讯" 文字标签
- 小地图玩家标记使用形状区分：□△○◇☆

### 可读性
- 最小字号：13px（720p 分辨率下可读）
- 正文对比度 >= 4.5:1
- 重要信息不要仅靠颜色传递（形状+文字+颜色三重编码）
- 分辨率适配：1280×720 / 1920×1080 / 2560×1440 三级 layout
