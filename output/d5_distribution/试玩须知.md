# 港区潜线 GANGLAND UNDERCOVER — 外部试玩须知（v0.3.1-demo）

> 分发包：`GanglandUndercover-0.3.1-demo-macOS.dmg`（158MB，2026-10-26 版）
> **请务必使用本版本**——0.3.0（10-21）修好了联机收消息；0.3.1（10-26）在此基础上
> 修掉了对局里所有地图文字左右镜像的问题，并把走廊/建筑画面做得更干净。
> 老包（≤10-21 13:30）联机不可玩，早于 10-21 的包更是收不到服务器消息。

## 一、安装（macOS）

1. 双击 DMG，把 `GanglandUndercover.app` 拖到任意位置（建议「应用程序」或桌面）。
2. 首次打开若提示"无法验证开发者"：**右键点击 App → 打开 → 再点打开**（只需一次）。
   或在终端执行：`xattr -cr /路径/GanglandUndercover.app`
3. 需要 **联网**（联机走 Unity Relay 中继，无需服务器/IP）。
4. 配置要求：Apple Silicon 或 Intel Mac，Metal 支持，macOS 12+。

## 二、双人联机 3 步开局

1. 两台机器各自打开游戏（同一路由器或不同网络都行）。
2. 一方：右侧「联机行动」→ 输入**行动代号**（**两台机器的代号不要相同**，见已知限制）→
   「初始化匿名身份」→「进入联机大厅」→ 创建房间（Bot 自动补位）→ 开始。
3. 另一方：进入联机大厅 → 在房间列表加入，或直接输入**房间码**（Host 大厅里能看到）。

对局目标：警察方靠完成任务攒证据链收网；黑帮方击倒他人至人数持平。你拿到哪方
开局随机，身份只在开场简报里展示给你自己。

## 三、操作

| 键 | 功能 |
|----|------|
| WASD | 移动 |
| E | 互动（推进任务，站到任务点上按住） |
| R | 报案（发现尸体时）/ 紧急铃 |
| Q | 击倒（仅黑帮侧，有冷却） |
| F | 职业技能（各职业不同，有冷却） |
| G | 拖动尸体（清道夫职业） |
| C | 查看监控 |
| M / I | 地图 / 案情板 |
| Enter | 发送聊天 |

聊天按频道分流：大厅全员、对局内附近可见、会议全员、死亡后只能看和跟鬼魂聊。

## 四、本次试玩重点（按优先级）

1. **联机基本盘**：两台机器能否顺畅同局？角色移动/任务/击倒/会议是否同步？
2. **掉线重连**（新功能）：对局中故意断网 10 秒再连（关 WiFi 再开）→ 用**相同行动代号**
   重新加入房间码 → 角色和身份应该原地恢复。
3. **聊天**：Host 发的消息是否只显示一次？死亡后能否看到会议讨论？
4. **职业技能**：F 技能是否有感知（视觉/效果）？
5. **可读性**：地图偏暗还是合适？走廊和房间能否分清？
   0.3.1 新变化——地图文字（任务名/房间名）应该全部**正向可读**（老版本是镜像的），
   走廊边多了货箱/油桶/排档桌等杂物，建筑边缘有了砖墙描边；如果你觉得画面
   太空或太挤，都请反馈。

## 五、已知限制（不是 bug，别报）

- **行动代号必须唯一**：同房间两人同名，掉线重连会认错人。
- 死亡后不能发言，只能旁观会议+跟其他鬼魂聊。
- 暂无 Windows 版；暂无中文以外的语言。
- 行动中离开房间，你的角色会被移除（90 秒内同代号重连可保身份）。

## 六、出问题怎么报

按 `反馈模板.md` 填写，附截图/录屏最好。崩溃的话：
`~/Library/Logs/DiagnosticReports/` 里找 Gangland 开头的最新文件一起发。
游戏运行日志：`~/Library/Logs/GanglandUndercover/Gangland Undercover/Player.log`
