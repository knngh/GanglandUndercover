# Gangland Undercover - UI 状态截图清单

> 版本: v0.2.0-dev | 日期: 2026-06-09 | 用于 PlayMode/人工验收

## 目标

这份清单用于验证当前 IMGUI + uGUI 混合阶段的可玩性和可读性。它不是“已完成截图”的记录，而是后续 UI 迁移和视觉回归的验收入口。

## 必拍状态

| # | 状态 | 检查点 | 优先级 |
|---|------|--------|--------|
| 1 | Lobby 初始界面 | 标题、玩家名、Host/Client/Relay、补 AI 开局入口可见 | P0 |
| 2 | Lobby Ready/Start | 玩家列表、Ready 状态、Start 可用/禁用逻辑清楚 | P0 |
| 3 | Opening 身份简报 | 角色、职业、阵营目标和倒计时不截断 | P0 |
| 4 | Action 完整 HUD | 阶段、存活、证据、任务、会议数、操作提示可读 | P0 |
| 5 | Action 小地图/案情板 | 小地图、玩家/任务/尸体线索不遮挡主操作 | P1 |
| 6 | Action 任务进行中 | 任务面板、进度条、完成/取消反馈清楚 | P0 |
| 7 | Action 尸体/报告提示 | 尸体标记、R 报案/紧急会议提示可见 | P0 |
| 8 | Action 击倒/技能按钮 | Q/F 等关键操作在合法场景出现、非法场景不误导 | P0 |
| 9 | Sabotage Blackout | 暗色遮罩、视野圈、危机提示可读 | P1 |
| 10 | Sabotage Lockdown | 门/封锁提示能被玩家识别 | P1 |
| 11 | Sabotage CommunicationJam | 通讯受限状态和聊天禁用反馈明确 | P1 |
| 12 | Meeting 开始 | 会议原因、倒计时、玩家列表、证据摘要可读 | P0 |
| 13 | Voting 投票 | 投票按钮、跳过投票、已投/未投状态明确 | P0 |
| 14 | Result 结算 | 胜负阵营、关键统计、重开/返回按钮可见 | P0 |
| 15 | Chat 输入/消息 | 输入框、频道标签、玩家名、消息内容不重叠 | P1 |
| 16 | Relay 状态 | 房间码、加入中/失败/成功状态不截断 | P1 |
| 17 | Host Migration | 迁移提示 overlay 居中、无空白/遮挡关键说明 | P2 |

## 视口矩阵

| 视口 | 用途 |
|------|------|
| 1280x720 | 最低常用桌面/窗口化验收 |
| 1920x1080 | 主要桌面验收 |
| 2560x1440 | 大屏 UI 密度验收 |

移动端暂不作为当前 Unity 桌面原型的强制截图口径。

## 通用验收标准

- 无 `NullReferenceException`、`MissingReferenceException` 或 UI 相关异常。
- 中文文字完整可读，不截断关键名词和按钮。
- 关键按钮尺寸稳定，hover/click 音效可触发。
- 会议/投票/结果界面不遮挡玩家需要决策的信息。
- IMGUI 与 uGUI 同屏时层级清楚，不出现相互覆盖导致无法操作。
- 资源化 UI/VFX 能正确加载，缺失资源应有 fallback 或日志可定位。

## 建议自动化方向

1. 在 PlayMode 中补固定分辨率截图 helper。
2. 先覆盖 Lobby、Action、Meeting、Voting、Result 五个 P0 状态。
3. 再把破坏状态和聊天输入纳入截图回归。
