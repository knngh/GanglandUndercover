## 一、角色目标稿 #2：Enforcer（黑帮打手）

### 1.1 基本信息

| 属性 | 值 |
|------|-----|
| 职业 | Enforcer（打手） |
| 阵营 | 黑帮（Gang） |
| 主色调 | 赤红 `#c0392b` + 黑色 `#1a1a1a` |
| 辅助色 | 暗金 `#b8860b`（腰带扣、头巾金线） |
| 角色定位 | 壮硕肌肉型，黑帮阵营的"可见力量" |
| 风格对比 | 与 Inspector（警察，警蓝+秩序感）形成明确阵营对视 |

### 1.2 身体比例（64×64 网格，对齐 Art Bible §3.1）

```
        头顶 y=0
  0-8   黑色头巾（宽15px，额前打结，结处暗金线条1px）
  8-14  脸部（偏深肤色 #d4a574，方脸宽13px，下巴棱角分明）
 14-18  颈部（2px过渡，比 Inspector 略宽1px）
 18-38  身体（赤红背心上衣，宽14px × 高20px，肩部肌肉轮廓外扩1px）
        → 背部：背心呈倒三角肌肉线条，肩胛骨处有暗色褶皱2px
 35-39  暗金腰带扣（宽14px × 高4px，中间圆形扣）
 38-50  黑色工装裤（各腿宽5px，比警察裤腿粗1px）
 48-54  黑色军靴（高6px，各宽7px，靴头方形）
        脚底 y=64
```

### 1.3 四方向关键区别

| 方向 | 面部/头部 | 身体 | 特殊 |
|------|----------|------|------|
| **Front（正面）** | 方脸+深肤色+黑色头巾额前打结，怒目（眉头下压1px），嘴部紧抿（横线1px） | 赤红背心正面，暗金腰带扣居中，双臂略外扩（比自然下垂外扩2px体现肌肉感） | 右手自然握拳状 |
| **Back（背面）** | 后脑勺（头巾包裹，黑色圆形），头巾尾端下垂3px | 赤红背心背面呈倒三角，肩胛骨处暗色线条 | 腰带扣位于背面中心线 |
| **Left（向左）** | 方脸侧轮廓，鼻子朝左突出2px，头巾侧面可见打结 | 背心侧面可见，右臂在前（略粗），左臂在后 | 身体宽14px不变 |
| **Right（向右）** | Left 的水平镜像 | 同Left镜像 | — |

### 1.4 与 Inspector 的视觉对比规则

| 维度 | Inspector（已定稿） | Enforcer（本稿） |
|------|-------------------|-----------------|
| 头饰 | 警帽（平顶、硬朗） | 头巾（柔软、打结） |
| 脸型 | 椭圆脸、偏白肤色 | 方脸、偏深肤色 |
| 体型 | 标准（体宽12px） | 壮硕（体宽14px） |
| 身体色 | 警蓝 `#2d6fba` | 赤红 `#c0392b` |
| 腰带 | 金色警徽腰带 | 暗金扣腰带 |
| 气质 | 秩序、冷静 | 暴力、压迫感 |

> ⚠️ **关键验收点**：两台角色并排放在 64×64 画布上，不看颜色也能区分职业和阵营。

## 二、角色目标稿 #3（补充）：UndercoverAgent（卧底）— 警察阵营伪装外观

### 2.1 基本信息

| 属性 | 值 |
|------|-----|
| 职业 | UndercoverAgent（卧底探员） |
| 阵营 | 警方（Police）— 但不显示警服 |
| 外观策略 | **便衣警察**：不穿制服，但保持警方阵营色系线索 |
| 主色调 | 暗紫 `#8e44ad`（兜帽）+ 深灰 `#4a4d52`（便衣外套） |

### 2.2 视觉描述

与 Enforcer、Inspector 都不同——**兜帽便衣**：
- 不穿制服、不戴警帽、不带肌肉感
- 深灰色连帽外套，兜帽拉起遮住头顶，只露出脸部下半部分
- 暗紫色兜帽为阵营识别线索（只有警方阵营角色能看到——此为游戏机制，美术层面画紫色兜帽）
- 体型为标准（同 Inspector，体宽12px）
- 外套下方露出暗袋（藏有警徽/手铐等暗示）

**设计意图**：在游戏画面中，其他玩家很难第一眼判断这是警察还是黑帮——这正是卧底角色的游戏性核心。

### 2.3 与 Inspector 的并排对比

| 维度 | Inspector | UndercoverAgent |
|------|-----------|-----------------|
| 帽子 | 警帽（暴露身份） | 兜帽（隐藏身份） |
| 身体 | 警蓝制服+警徽 | 深灰便衣+暗袋 |
| 阵营信号 | 警蓝 = 警察 | 暗紫 = 隐藏警察 |
| 可读性 | 一眼警 | 一眼"不确定" |

## 三、房间目标稿：港区电房（Electric Room）

### 3.1 房间参数

| 属性 | 值 |
|------|-----|
| 地图 | 港区 (Harbour) |
| 房间名 | 电房 (Electric Room) |
| 房间尺寸 | 6×5 tile（192×160 px） |
| 功能 | Wire 任务站部署点 + 停电破坏可能触发点 |
| 氛围 | 工业、危险、低光照 |

### 3.2 Tile 构成

```
    天花板
  ┌──────────────────────┐
  │ 配电柜墙面（大）      │  ← 北墙，大型配电柜 sprite (64×96 px)
  │ ████████████████████ │
  │ ██ ⚡ ██ ⚡ ██ ⚡ ██ │  ← 配电柜上有红色危险标记和仪表
  │                      │
  │  Wire 任务站          │  ← 西墙中部，壁挂式配电箱 (32×48 px)
  │  [配电箱]             │
  │                      │
  │     (空地板区域)      │  ← 玩家站立/行走区
  │                      │
  │           [铁门]      │  ← 南墙右侧，铁门 (16×32 px)，房间唯一入口
  └──────────────────────┘
```

### 3.3 Tile 清单

| Tile | 文件名 | 尺寸 | 颜色 | 说明 |
|------|--------|------|------|------|
| 地板 | `tile_harbour_electric_floor_01.png` | 32×32 | `#4a4d52` 金属网格 | 网格铁板，2px 粗格线，间距8px |
| 墙壁 | `tile_harbour_electric_wall_01.png` | 32×32 | `#3a3c42` 暗灰混凝土 | 素混凝土墙，有竖向裂缝1px |
| 配电柜（大） | `tile_harbour_electric_prop_cabinet.png` | 64×96 | `#6a7a8a` 金属灰 | 大型壁挂配电柜，含仪表/开关/指示灯 |
| 配电箱（任务站） | `prop_task_wire_idle.png` | 32×48 | 见 E4 §2.1 | Wire 任务站，独立交付 |
| 铁门 | `tile_harbour_electric_door_01.png` | 16×32 | `#5a5a5a` | 铁门含铆钉4颗和圆形把手 |
| 电缆束 | `tile_harbour_electric_prop_cable_01.png` | 8×32 | `#2a2a2a` | 从配电柜底部延伸出的电缆束 |
| 危险标记 | `tile_harbour_electric_prop_danger.png` | 16×16 | 黄底 `#f1c40f` + 黑字 ⚡ | 三角警告标记，贴在配电柜上方 |
| 应急灯 | `tile_harbour_electric_prop_light.png` | 8×16 | `#c0392b` 红 + `#aa0000` 暗红 | 壁挂应急红灯，停电时发光 |

### 3.4 关键视觉锚点（验收标准）

- [ ] 进门后第一眼看到**配电柜墙面**（占满整个北墙），这是房间的视觉焦点
- [ ] **Wire 任务站**（配电箱）在配电柜左下方，有霓虹黄光环——远距离可识别任务位置
- [ ] **危险标记** 黄色三角 ⚡ 在配电柜上方——警示感
- [ ] **电缆束** 从配电柜延伸到地面——工业真实感
- [ ] **铁门** 只有一扇（南墙右侧）——封闭空间压迫感
- [ ] 地面金属网格与港区其他房间的水泥/木地板明确区分
- [ ] 整体色调暗冷，配合环境光 → 停电破坏时效果最明显（应急红灯成为唯一光源）

### 3.5 与港区其他房间的视觉关系

电房是港区唯一**全封闭+工业危险**定位的房间。与同地图其他房间的对比：

| 房间 | 地板 | 墙壁 | 氛围 |
|------|------|------|------|
| 电房 | 金属网格 | 暗灰混凝土+配电柜 | 工业危险 |
| 货柜场 | 水泥 | 货柜+铁丝网 | 开阔工业 |
| 茶餐厅 | 木地板 | 瓷砖+玻璃窗 | 生活温馨 |
| 夜市 | 水泥地 | 摊位背板+霓虹 | 热闹市井 |
| 监控室 | 防静电 | CRT屏幕墙 | 科技监控 |

这种对比确保玩家跑图时能一眼区分房间类型。

## 五、评审门禁

目标稿评审会检查：

1. **Enforcer vs Inspector 并排**：不看颜色能否区分职业？阵营识别是否成立？
2. **电房 vs 茶餐厅（已有目标稿）**：两个房间并列时，氛围和功能区分是否明确？
3. **像素风格一致性**：所有 sprite 之间是否有统一的笔触密度、AA 程度、细节级别？
4. **E8 命名规范对齐**：文件名是否符合 `chr_` / `tile_` 前缀规则？
5. **Art Bible §9 光照规则**：电房的暗冷调是否与全局光照方向一致？

**通过标准：3/3 评审人签字。不通过则修订目标稿，不进入 M2 批量生产。**
