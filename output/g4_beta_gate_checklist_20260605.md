# G4 封测 Gate Checklist

日期：2026-06-05  
状态：封测准入条件定义

## 1. 封测准入门槛

### 1.1 稳定性要求
- [ ] 72 小时连续测试无 P0 阻断问题（崩溃、无法连接、对局卡死）
- [ ] 72 小时无 P1 问题（功能不可用但可绕过）
- [ ] 至少 3 局完整 6 人对局在 clean machine 上验证

### 1.2 功能完整性
- [ ] 3 张地图（港区/警署/九龙城寨）均可完整游玩
- [ ] 7 个核心职业可选择
- [ ] 5 种破坏类型可触发和修复
- [ ] 会议/投票/出局流程完整
- [ ] 房间创建/加入/离开流程无阻断
- [ ] Relay 连接可用（macOS 和 Windows）

### 1.3 构建要求
- [ ] macOS 构建可启动
- [ ] Windows 构建可启动
- [ ] Clean checkout 构建通过（不依赖 ThirdParty/AssetStore 目录）
- [ ] 构建产物 < 500MB（压缩后）

## 2. 版本和回滚

### 2.1 版本号规范
```
主版本.次版本.修订号-阶段
示例: 0.9.0-beta1
- 0.x 封测阶段
- 1.0 正式发布
```

### 2.2 回滚计划
- [ ] Git tag 对应每个可发布构建
- [ ] 上一稳定构建保留在 Builds/archive/
- [ ] 回滚命令: `git checkout <tag> && BuildScript.BuildAll()`

## 3. Bug Tracker

### 3.1 严重度定义
| 等级 | 定义 | 示例 |
|------|------|------|
| P0 | 阻断，游戏不可玩 | 崩溃、无法连接、对局卡死 |
| P1 | 功能不可用但有绕过 | 破坏按钮无效、投票不显示 |
| P2 | 体验问题 | UI 错位、文字错误 |
| P3 | 建议优化 | 配色、动画改进 |

### 3.2 统计目标
- P0 数量 = 0（准入硬性要求）
- P1 数量 <= 3
- P2/P3 不限但需记录

## 4. 测试说明

### 4.1 封测者需知
1. 当前版本为封闭测试，不代表最终品质
2. 需要至少 4 人在线才能开局
3. 已知问题列表见 KnownIssues.md
4. 遇到问题请在反馈渠道提交（截图/日志/重现步骤）

### 4.2 反馈模板
```
版本: [版本号]
平台: [macOS/Windows]
人数: [4/6/8/10]
地图: [港区/警署/九龙城寨]
问题描述: [详细描述]
重现步骤: [1. 2. 3.]
截图/日志: [附件]
```

## 5. 发布前最终检查

- [ ] README 描述与实际功能一致
- [ ] UI 无 Vivox/语音过期承诺
- [ ] 中文字体无缺字
- [ ] 英文 fallback 可用
- [ ] 设置持久化验证通过
- [ ] 色盲模式可用（替代符号）
- [ ] 720p 最小分辨率可用
- [ ] 无 gitignored 资源依赖

# 4. 分发
# 通过内部渠道分享 Builds/macOS/ 或 Builds/Windows/
