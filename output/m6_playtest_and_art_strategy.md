## Task 6.3 Tile/Sprite 美术替换策略

### 6.3.1 替换原则

1. **逻辑层不动**：碰撞 Rect、walkable 区域、任务交互点、暗线节点坐标全部保持不变
2. **坐标同源**：所有美术资产位置走 `OnlineMapService.ScaleMapPosition()`
3. **逐区域替换**：先替换一个房间验证管线，再铺开全部 12 个房间
4. **A/B 对比**：替换前后截图覆盖对比，确保路线不变

### 6.3.2 资产规格

| 资产类型 | 格式 | 尺寸 | PPU | 说明 |
|---|---|---|---|---|
| 地板 Tile | PNG Sprite | 256×256 | 100 | 无缝拼接 |
| 墙壁 Tile | PNG Sprite | 256×128 | 100 | 带阴影厚度 |
| 房间装饰 | PNG Sprite | 可变 | 100 | 挂画/海报/货架 |
| 走廊地面 | PNG Sprite | 256×256 | 100 | 带导向线 |
| 暗线格栅 | PNG Sprite | 128×128 | 100 | 半透明可交互提示 |
| 监控标记 | UI Icon | 64×64 | 200 | 小地图图标 |

### 6.3.3 替换管线

```
灰盒 Room → 美术 Room Sprite → 替换 CreateProp → 对照截图 → 通过
                                                              ↓ 不通过
                                                         调整坐标/尺寸
```

### 6.3.5 Sorting 层级

```
Z-Layer (远→近):
  背景远景     z=1.0~2.0
  墙壁         z=0.5~0.8
  房间装饰     z=0.3~0.5
  地面         z=0.0
  角色         z=-0.05~-0.2 (由 SortingOrderForZ 自动计算)
  前景遮挡     z=-0.5~-1.0
```
