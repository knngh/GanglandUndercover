## 6. 独特机制：Tide Timer（潮汐计时器）

### 6.1 机制概述

货轮下层的部分区域会周期性被海水淹没，迫使玩家向上层甲板移动，制造自然的强制集合效果。

### 6.2 潮汐周期

| 阶段 | 时长 | 效果 |
|------|------|------|
| 退潮期 | 45 秒 | 下层甲板正常可通行 |
| 涨潮警告 | 5 秒 | 下层甲板闪烁蓝色警报，播放水声预警音效 |
| 涨潮期 | 20 秒 | 下层甲板被水淹没，不可通行，滞留玩家受到减速惩罚（移速 x0.3） |
| 排水期 | 5 秒 | 水位下降，恢复正常 |
| 总周期 | 75 秒 | — |

### 6.3 受影响区域

| 区域 | 是否受潮汐影响 | 影响程度 |
|------|--------------|---------|
| 引擎室 | 是（轻度） | 涨潮时地板部分积水，移速 x0.6 |
| 货舱 | 是（重度） | 涨潮时完全被淹，不可通行 |
| 装卸区 | 否 | 中层甲板，不受影响 |
| 集装箱迷宫 | 否 | 中层甲板，不受影响 |
| 海关办公室 | 否 | 中层甲板，不受影响 |
| 船员宿舍 | 否 | 中层甲板，不受影响 |
| 驾驶室 | 否 | 上层甲板，不受影响 |
| 无线电室 | 否 | 上层甲板，不受影响 |

### 6.4 潮汐对游戏机制的影响

| 机制 | 潮汐影响 | 设计意图 |
|------|---------|---------|
| 任务执行 | 货舱内任务（T13, T14）在涨潮期不可操作 | 自然打断任务节奏，防止任务速通 |
| 击杀 | 涨潮期下层甲板人少，但滞留者移速降低 | Gang 可以利用潮汐制造困杀 |
| 通风管 | 下层通风管出口（V5, V6）在涨潮期不可使用 | 防止 Gang 通过通风管逃生到被淹区域 |
| 紧急任务 | CriticalReactor 在引擎室 — 涨潮时修复困难 | 增加紧急任务难度 |
| 会议 | 涨潮时下层甲板玩家自动向中层移动 | 自然促进信息交流 |

### 6.5 Tide Timer 配置参数

| 参数 | 值 | 调参建议 |
|------|-----|---------|
| tideCycleSeconds | 75 | 60-90 范围 |
| ebbDuration | 45 | 35-55 范围（越长=下层可用时间越多） |
| floodDuration | 20 | 15-30 范围（越长=下层封锁越久） |
| 重度区域移速倍率 | 0.3 | 0.2-0.5 范围 |
| 轻度区域移速倍率 | 0.6 | 0.4-0.8 范围 |

| Lockdown | 海关办公室门锁 | 修复门锁（T7 附近） | 6s |
| CriticalReactor | 引擎室 | 两人同时按键 | 30s 限时 |

### 9.2 潮汐与破坏的交互

| 场景 | 效果 |
|------|------|
| 涨潮期 + Blackout | 下层黑暗+积水，极度危险 — DarkVision 能力价值极高 |
| 涨潮期 + CriticalReactor | 必须在积水中修复引擎，难度最高 |
| 涨潮期 + Lockdown（海关办公室） | 中层通道被封锁，迫使走另一条路 |

## 10. MapValidator 验证标准

### 10.1 通用验证（继承自 D2 标准）

- 所有房间从会议点（驾驶室）可达：BFS 连通
- 走廊宽度 >= 1.0 设计单位：通道标准
- 通风管网络是连通图：图论验证
- 摄像头覆盖率 50-70%：面积计算
- 出生点数 >= MaxMeetingSeats（10 个出生点）
- 任务点数 >= 12（16 个任务点）

### 10.2 货轮特有验证

| 验证项 | 标准 | 说明 |
|--------|------|------|
| 潮汐影响区域标记正确 | 货舱为重度区，引擎室为轻度区 | TideCollider 区域 |
| 涨潮期不可通行区域有物理阻挡 | BoxCollider2D 在涨潮时启用 | 防止玩家穿模 |
| 潮汐不影响上层/中层甲板 | ebb/flood 切换不影响非受影响区域 | 确保不影响正常游戏 |
| 通风管出口不在重度潮汐区 | V5, V6 在涨潮期自动禁用 | 通风管出口安全 |
| 下层任务在涨潮期不可交互 | T13, T14 交互被阻挡 | TaskCollider 联动 |
| 引擎室紧急任务在涨潮期仍可修复 | 但移速降低增加难度 | CriticalTask 兼容 |

### 10.3 潮汐系统验证清单

- 潮汐周期计时器正确运行（75 秒一轮）
- 涨潮警告视觉效果（蓝色闪烁）正确显示
- 涨潮音频（水声）正确播放
- 重度区域物理碰撞在涨潮时启用
- 轻度区域移速修正在涨潮时生效
- 下层通风管出口在涨潮时禁用
- 下层任务站在涨潮时禁用交互
- 潮汐状态同步到所有客户端
- 排水期后所有状态正确恢复
