## 1. 画面基调

**题材**：香港港区警匪暗战，夜雨霓虹。

| 维度 | 规范 |
|------|------|
| 主色调 | 港夜深蓝 `#1a1c2c` — 所有场景底色 |
| 暖色高光 | 霓虹暖黄 `#f4a236` — 任务点、UI 强调、灯牌 |
| 警方色系 | 警蓝 `#2d6fba` / 青 `#1a9eaa` — Inspector、Tech |
| 黑帮色系 | 赤红 `#c0392b` / 灰黑 `#7f8c8d` — Enforcer、Fixer |
| 卧底色系 | 暗紫 `#8e44ad` — UndercoverAgent |
| 法医色系 | 墨绿 `#2e8b57` — Forensics |
| 车手色系 | 金黄 `#d4a017` — Driver |
| 环境光 | 全局偏暗（夜场），点光源由霓虹牌/街灯/警灯提供 |
| 雨后反光 | 地面加蓝色/紫色 low-alpha 高光条纹 |

**情绪关键词**：紧张、猜疑、暗流涌动、港味霓虹。

**参考**：《Sleeping Dogs》夜市场景、《John Wick 4》大阪霓虹、《Among Us》信息可读性。

## 2. 像素规格

| 类别 | 尺寸 | 说明 |
|------|------|------|
| 角色 sprite | 64×64 px | 全身含头+身体+腿，脚底为 pivot 点 y=0 |
| 角色头像 | 64×64 px | 裁剪角色头部区域，加职业色边框 |
| 小地图图标 | 16×16 px | 玩家标记/任务点/尸体/破坏 |
| 地板 tile | 32×32 px | 无缝拼接，4方向 repeat |
| 墙壁 tile | 16×16 px | 垂直平铺 |
| 道具 sprite | 32×32 px | 货柜/桌子/档案柜等 |
| UI 图标 | 32×32 或 64×64 px | 按钮/状态图标 |
| VFX sprite | 64×64 px | 特效 overlay |
| 全屏遮罩 | 4×4 px（拉伸） | 降 draw call |

**像素密度**：Pixels Per Unit = 32（每世界单位 32 像素）。

**滤镜模式**：Point（无模糊），保持像素锐利感。UI 层可用 Bilinear。

## 3. 角色规范

### 3.1 身体比例（64×64 网格）

```
        头顶 y=0
  0-8   帽子/头盔（高 8px，宽 15px）
  8-14  脸部（肤色，椭圆形 12×6）
 14-18  颈部（肤色，2px 过渡）
 18-38  身体（职业色，宽 12px × 高 20px）
 35-39  腰带（辅助色，宽 14px × 高 4px）
 38-50  腿部（暗色，各宽 4px）
 48-54  靴子（黑色，各宽 6px）
        脚底 y=64
```

### 3.2 四方向

- **正面 (Front)**：脸部可见、帽子居中、手臂在身体两侧自然下垂
- **背面 (Back)**：后脑勺（职业色圆形）、看不到脸、身体和腿部与正面一致
- **左侧 (Left)**：向画面左侧移动，鼻子朝左，右臂在前
- **右侧 (Right)**：左侧的镜像

### 3.3 动画帧

- 行走：3 帧循环（双腿交替 ±1px、手臂微摆），帧间隔 0.25s
- 待机：0 帧（静止，无动画）
- 交互：右手抬起 3px（1 帧）
- 击倒：身体横躺 + 血迹散布（1 帧）
- 尸体：击倒帧 + 红色半透明 X 标记（1 帧）
- 鬼魂：正面帧 × 灰色调色板 + α=0.35

### 3.4 职业视觉识别

| 职业 | 帽子 | 身体特征 | 配色 |
|------|------|----------|------|
| Inspector | 警帽（平顶） | 警徽腰带 | 警蓝+白 |
| Tech | 耳机 | 电路腰带 | 青+暗灰 |
| Forensics | 面罩 | 证据袋 | 墨绿+白 |
| Enforcer | 头巾 | 肌肉轮廓 | 赤红+黑 |
| Fixer | 鸭舌帽 | 工具箱腰带 | 灰黑+暗红 |
| UndercoverAgent | 兜帽 | 暗袋 | 暗紫+黑 |
| Driver | 头盔 | 护膝 | 金黄+黑 |
| Mole | 与 Inspector 相同外观 | — | 伪装警蓝 |

**隐藏阵营原则**：Mole 外观 = Inspector（不暴露隐藏身份），UndercoverAgent 不显示警方色系。

## 4. 地图规则

### 4.1 分层排序

| Sorting Layer | Order 范围 | 内容 |
|---------------|-----------|------|
| Ground | 0-9 | 地板、地面装饰 |
| FloorDecal | 10-19 | 血迹、尸体标记、证据残留 |
| Props | 20-29 | 道具、家具、遮挡体 |
| Walls | 30-39 | 墙体、门框 |
| Actors | 40-49 | 玩家角色 |
| Overhead | 50-59 | 屋顶遮罩、灯牌 |
| VFX | 60-79 | 特效、破坏遮罩 |
| UIWorld | 80-99 | 世界 UI（任务标签、交互提示） |

Actors 层内按 y 坐标动态排序（y 越小 = 越靠前 = 越靠近摄像机）。

### 4.2 房间可读性

- 每个房间有独特地板 tile 和颜色基调（详见 MapTilePalette）
- 房间入口用墙壁缺口标示（不额外加门 sprite）
- 任务站有发光环（α=0.4，脉冲动画 2Hz）
- 暗线入口用通风管格栅标示
- 监控摄像头有红色 LED 指示灯

### 4.3 三张地图视觉区分

| 地图 | 地板 | 墙壁 | 环境 |
|------|------|------|------|
| 港区 | 水泥/铁锈/木纹 | 红砖+水泥 | 码头吊臂、货柜、湿地反光 |
| 警署 | 瓷砖/灰墙 | 水泥+警戒线 | 文件柜、证物架、监控屏 |
| 九龙城寨 | 木纹/红砖/石板 | 砖纹+霓虹牌 | 茶餐厅、药材柜、麻将桌、铁栏 |

## 5. UI 规则

### 5.1 设计语言

- **边框**：1px 霓虹暖黄 `#f4a236` 框线，圆角 4px
- **面板底色**：深蓝黑 `rgba(4,5,7,0.85)`，半透明
- **按钮**：暗底 `rgba(16,19,24,1)` + 悬停亮 10%
- **字体**：`LegacyRuntime.ttf`（中文 fallback），字号 14-24
- **状态色**：
  - 正常/存活 = 白
  - 警告/嫌疑 = 暖黄
  - 危险/死亡 = 红
  - 完成/证据 = 绿
  - 信息/冷却 = 蓝
  - 出局/禁用 = 灰

### 5.2 关键界面

| 界面 | 重点 |
|------|------|
| 主菜单 | 港区夜景背景 + 标题 neon 字体 |
| 大厅 | 玩家列表 + 地图选择 ← → 键 + 房间码 |
| 行动 HUD | 左下任务进度 + 右下手持能力 + 顶部计时/证据条 |
| 会议 | 圆桌背景 + 投票卡牌翻转 + 嫌疑人高亮 |
| 结算 | 胜负结果 + 职业揭晓 + 隐藏目标达成 |

### 5.3 响应式

- 参考分辨率：1600×900（横屏 16:9）
- 最小支持：1280×720
- Canvas Scaler：Scale With Screen Size，Match=0.5

## 6. VFX 规则

| 事件 | 视觉 | 时长 | 层级 |
|------|------|------|------|
| 击杀 | 血迹溅射 + 尸体红色 X 标记 | 持久 | FloorDecal |
| 停电 | 全屏暗蓝遮罩（α=0.75）+ 应急红灯闪烁 | 破坏持续期间 | VFX |
| 锁门 | 红色 × 标记 + 倒计时数字 | 破坏持续期间 | VFX |
| 通讯干扰 | 小地图雪花噪点 + UI glitch 效果 | 破坏持续期间 | VFX |
| 证据泄露 | 红色脉冲环 + 证据条闪红 | 破坏持续期间 | VFX |
| 巡逻警报 | 黄橙扇形警示灯 | 破坏持续期间 | VFX |
| 技能施放 | 各职业专属短特效（≤1s） | 0.5-1s | VFX |
| 会议召集 | 屏幕闪红 → 切入会议 UI | 0.5s | VFX |

**原则**：VFX 不能遮挡核心 UI 和角色识别。破坏效果优先用遮罩/边框变化，不用粒子爆炸。

## 8. 目标稿描述

### 8.1 角色目标稿：Inspector（警探）

一个正面的 64×64 像素角色，警蓝色平顶帽，白色皮肤脸部，深蓝色上衣（带金色警徽腰带），黑色裤子和靴子。角色站立姿势，双臂自然下垂。背景为透明的港区码头场景（灰蓝调，非白底）。

### 8.2 房间目标稿：港区茶餐厅

一张 32×32 tile 铺成的茶餐厅房间（约 256×192 像素区域），木纹地板，红砖墙壁（左侧和上方），右侧有玻璃展示柜，中央有圆形餐桌和卡座。门外（下方缺口）透出走廊水泥地面。上方悬挂霓虹「茶」字灯牌（暖黄色）。

### 8.3 UI 目标稿：会议投票界面

1600×900 横屏 UI 截图：中央圆形会议桌（深色纹理），周围 8 个玩家头像卡牌（4 上 4 下）。上方显示「会议中 15s」倒计时和案件原因。下方显示投票面板（各玩家旁有投票按钮和跳过按钮）。背景为暗蓝半透明遮罩，保持会议沉浸感。色调统一采用港夜霓虹风格。

## 9. 光照与材质规则

### 9.1 全局光照

| 属性 | 规范 | 说明 |
|------|------|------|
| 环境光颜色 | `#1a1c2c` (深蓝黑) | 所有场景的底色基调 |
| 环境光强度 | 0.6 (60%) | 偏暗，突出点光源 |
| 光照方向 | 无全局定向光 | 所有光照由场景内点光源提供 |
| 光色温 | 暖黄 + 冷蓝混合 | 霓虹灯（暖黄）为主，辅以冷蓝月光/警灯 |

### 9.2 场景点光源规则

| 光源类型 | 颜色 | 强度 | 半径 | 出现位置 |
|----------|------|------|------|----------|
| 霓虹灯牌 | `#f4a236` 暖黄 | 0.8 | 96px | 夜市、茶餐厅、后巷 |
| 警灯 | `#2d6fba` 警蓝 | 0.6 | 64px | 警署、海关区、指挥广场 |
| 应急红灯 | `#c0392b` 红 | 0.7 (脉冲) | 48px | 停电时所有房间 |
| 任务站光环 | 各状态色 | 0.4 (脉冲2Hz) | 32px | 所有任务站 |
| 监控摄像头 LED | `#c0392b` 红 | 0.3 | 16px | 监控室、走廊 |
| CRT 屏幕辉光 | `#1a9eaa` 青绿 | 0.5 | 48px | 监控室、Download 任务站 |

### 9.3 材质表面属性

| 表面类型 | 反光率 | 颜色偏移 | 适用 |
|----------|--------|----------|------|
| 水泥地面 | 低反光 (10%) | +5% 蓝灰 | 后巷、暗渠、仓库 |
| 金属网格/铁板 | 中反光 (25%) | +10% 蓝白高光条纹 | 货柜场、电房 |
| 瓷砖地面 | 高反光 (40%) | +15% 白色高光斑块 | 警署大厅、地下诊所 |
| 木地板 | 低反光 (10%) | +5% 暖棕 | 茶餐厅、药材铺、麻将馆 |
| 湿地/雨后 | 高反光 (50%) | +20% 蓝紫 overlay 条纹 | 港区所有室外区域 |
| 玻璃/镜面 | 最高反光 (60%) | +30% 白色高光点 | 审讯室单面镜、金融楼玻璃幕墙 |

**湿地反光规则**：港区地图所有室外区域（货柜场地面、后巷地面、天台）叠加蓝色/紫色 low-alpha（α=0.15）高光条纹，条纹宽2px、间距8px、与地面 tile 方向一致。仅在 Sorting Layer = FloorDecal, Order=8 渲染。

### 9.4 阴影规则

| 属性 | 规范 |
|------|------|
| 角色阴影 | 脚底椭圆黑色半透明圆（α=0.3，16×6px），Sorting Layer=Ground, Order=5 |
| 道具阴影 | 底部方形黑色半透明（α=0.2，随道具尺寸缩放），Sorting Layer=Ground, Order=4 |
| 墙壁投影 | 无（俯视视角不需要墙壁投影） |
| 动态光源阴影 | 不做——像素风格不追求真实光影 |

### 9.5 昼夜/天气变体

| 变体 | 环境光 | 反光 | 适用地图 | 优先级 |
|------|--------|------|----------|--------|
| 港区·雨夜 | `#1a1c2c` + 湿地反光 | 高 | 港区（默认） | P0 |
| 警署·夜间 | `#141420` 更暗 | 中（室内灯光为主） | 警署（默认） | P0 |
| 九龙城寨·深夜 | `#0f0f1a` 最暗 | 高（霓虹密集） | 九龙城寨（默认） | P0 |
| 港区·黄昏（可选） | `#2a1a0c` 暖暗 | 低 | 港区变体 | P2 |
| 警署·白天（可选） | `#d4c8b0` 明亮 | 低 | 警署变体 | P3 |

**封测阶段只做默认变体**（每张图一个），可选变体延后。

## 10. 技术约束

- 所有 sprite 使用 Point filter（像素锐利）
- Sprite Atlas 按地图/类别分组，减少 draw call
- 角色 sprite 用 SpriteRenderer.color 着色（不同职业用同一 sprite sheet）
- 地图 tile 在 GreyboxMapBuilder 中以 SpriteRenderer 平铺
- VFX 遮罩用全屏 quad + SpriteRenderer（sortingOrder=500+）
- 构建不依赖 `Art/ThirdParty/` 和 `Resources/AssetStore/`
