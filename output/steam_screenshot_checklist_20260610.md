## 截图要求

- 分辨率: **1920×1080**（Steam 要求至少 1280×720）
- 格式: PNG 或 JPG
- 无水印、无 FPS 计数器、无 Unity Editor 窗口边框
- 不包含 OnGUI 调试面板（如有 `[Debug]` 则关闭）
- 色盲模式: 关闭
- 语言: 截图时用中文，English 用户会在商店页看到对应语言的截图（Steam 不自动翻译截图，但可取"游戏内截图"不带对话框的风格）

---

## 拍摄方式

```
1. Unity Editor → Stage1VerticalSlice 场景
2. PlayMode → 全屏
3. 导航到目标界面
4. Gangland > Screenshots > Capture Current Screen (4K)
5. 后期缩放到 1920×1080
```

或使用系统截图工具（macOS: Cmd+Shift+3）截取全屏。
