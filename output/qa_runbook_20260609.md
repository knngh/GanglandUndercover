# Gangland Undercover — 手工 QA 执行脚本

> 版本: 2026-06-09 | 环境: macOS Editor PlayMode | 预计耗时: 20-25 分钟

---

## 前置检查

```
□ Unity Editor 打开 Stage1VerticalSlice 场景
□ Console 窗口清空（Clear 按钮）
□ 语言: zh-CN（Settings 默认）
□ 色盲模式: 0（关闭）
```

---

## 流程 1: 登录 (2 min)

| 步骤 | 操作 | 预期 | ✓ |
|------|------|------|-----|
| 1.1 | 点击 Play，观察主菜单右侧联机面板 | 看到 "登 录 / 联 机" 标题 + "匿 名 登 录" 按钮 | ☐ |
| 1.2 | 观察登录状态行 | 显示 "登录: 匿名账号将在进入大厅后初始化..." | ☐ |
| 1.3 | 点击 "匿 名 登 录" | 几秒后状态变为 "匿名账号已就绪 \| PlayerId ..." | ☐ |
| 1.4 | 再次点击 "匿 名 登 录" | 不报错，状态不变 | ☐ |
| 1.5 | Console 检查 | 无红色 Error | ☐ |

## 流程 2: 设置 (5 min)

| 步骤 | 操作 | 预期 | ✓ |
|------|------|------|-----|
| 2.1 | 主菜单右下观察 | 看到 "音量 80% \| 画质 高 \| 全屏 \| 色盲 0" | ☐ |
| 2.2 | 点击 "打开设置" | 半透明深色覆盖层弹出，标题 "设 置 中 心" | ☐ |
| 2.3 | 覆盖层内容检查 | 5 个滑块 + 8 个按钮 + 底部 "设置会立即保存并应用" | ☐ |
| 2.4 | 拖主音量滑块到最左 | 音量变化，值为 0 | ☐ |
| 2.5 | 点击 "画质" 按钮 3 次 | 循环: 高→极致→低→中 | ☐ |

| 2.7 | 点击 "色盲" 按钮 | 循环 0→1→2→3 | ☐ |
| 2.8 | 点击 "重置设置" | 所有值恢复默认（音量 80%/画质 高/全屏/色盲 0） | ☐ |
| 2.9 | 点右上角 "关闭" | 覆盖层消失，主菜单恢复 | ☐ |
| 2.10 | 确认主菜单状态行更新 | 与设置内值一致 | ☐ |
| 2.11 | 把音量改为 40%、画质改为 "低"、色盲改为 1 | 关闭设置 | ☐ |

| 2.13 | Console 检查 | 无 Error | ☐ |
