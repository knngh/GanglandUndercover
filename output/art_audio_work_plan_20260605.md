## 二、总体推进策略

### 2.1 并行推进原则

```
美术线：角色 → 港区地图 → 任务站道具 → UI → VFX → 警署/九龙城寨 → Atlas/治理
音频线：P0 SFX → 破坏音效 → 环境音 → BGM → 任务细节音效 → 脚步声 → 结算变体
                                                        ↓
                                                [两线可并行，无强依赖]
```

### 2.2 优先级定义

| 优先级 | 含义 | 判断标准 |
|--------|------|----------|
| **P0** | 封测前必须完成 | 无此资产 = 游戏不可展示或体验严重受损 |
| **P1** | 封测前强烈建议完成 | 显著改善体验，不完成会有明显缺失 |
| **P2** | 封测后补完 | 锦上添花，不影响核心可玩性 |
| **P3** | 正式发布前补完 | 可选增强 |

### 2.3 交付策略

**不追求一次性全部交付。** 采用「垂直切片」策略：
- 每阶段产出**可立即集成、可截图验收、可试玩验证**的资产。
- 杜绝「攒一批再导入」——资产到一批，导入一批，验证一批。
- 程序化占位作为 fallback 始终保持可用。
