# E4 任务站道具 + E7 音频系统

日期：2026-06-05

## E4 11种小游戏任务站道具外观

每种任务站在地图中应有独特的视觉道具，不再只是 UI 弹窗。

| 任务站 | 道具外观 | 尺寸 | 颜色系 |
|--------|---------|------|--------|
| Wire/Repair 修电 | 配电箱 + 线缆 + 火花粒子 | 2×1 tile | 金属灰/电蓝 |
| Keypad 密码 | 挂墙键盘面板 + LED 灯 | 1×1 tile | 暗灰/绿 LED |
| SwipeCard 刷卡 | 立式门禁读卡器 + 证件槽 | 1×0.5 tile | 白/黑 |
| Scan 扫描 | 平台扫描仪 + 证物托盘 | 2×1 tile | 医疗白/银 |
| Download 下载 | 桌面终端 + 进度屏 | 1×1 tile | 暗灰/蓝屏 |
| Sort 分拣 | 档案柜 + 分拣台 | 2×1 tile | 木棕/灰 |
| Memory 记忆 | 灯格板 + 按钮 | 1×1 tile | 白/蓝/红/绿 LED |
| Tap 节奏 | 按钮台 + 节奏灯条 | 1×0.5 tile | 暗灰/彩灯 |
| Calibrate 校准 | 仪表盘 + 旋钮 | 1×1 tile | 面板灰/红绿针 |
| Asteroid (雷达追踪) | 雷达控制台 + 示波器 | 2×1 tile | 暗绿/雷达荧屏 |
| EvidenceArchive 证据 | 证据柜 + 照片墙 | 2×2 tile | 警蓝/白板 |

### 状态可读性
每个任务站 4 种状态：
- **待激活** — 道具高亮闪烁（黄边）
- **进行中** — 道具发光（蓝边）+ 进度条
- **已完成** — 道具变绿 + 勾号图标
- **被破坏** — 道具变红 + 火花/冒烟粒子

## E7 音频事件系统

### 音频事件清单

**UI (8 事件)**
| 事件 | 触发 | 音频 |
|------|------|------|
| UI_Click | 按钮点击 | 短促 click (0.1s) |
| UI_Hover | 鼠标悬浮 | 轻柔 tick (0.05s) |
| UI_Error | 操作失败 | 低嗡 + buzz (0.3s) |
| UI_Confirm | 确认操作 | 清脆 ding (0.2s) |
| UI_Ready | 准备就绪 | 上升 chime (0.5s) |
| UI_Countdown | 倒计时 3-2-1 | 3 声 tick + 1 声 bell |
| UI_Win | 胜利 | 激昂短 BGM (3s) |
| UI_Lose | 失败 | 低沉弦乐 (3s) |

**任务 (4 事件)**
| Task_Start | 开始任务 | 机械启动声 (0.3s) |
| Task_Progress | 任务进度过半 | 上升提示音 (0.2s) |
| Task_Complete | 任务完成 | 成功音效 (0.8s) |
| Task_Fail | 任务失败 | 失败蜂鸣 (0.5s) |

**游戏 (6 事件)**
| Kill | 击倒 | 沉闷撞击 + 倒地 (0.8s) |
| Report_Body | 发现尸体报案 | 尖锐报警声 (1.5s) |
| Meeting_Call | 会议召集 | 警铃 (2s) |
| Vote_Cast | 投票 | 纸张/卡片音 (0.3s) |
| Eject | 出局 | 沉重门关闭 (1s) |
| End_Reveal | 结算揭示 | 揭示旋律 (5s) |

**破坏 (5 事件)**
| Blackout_On | 停电 | 电流切断 + 应急灯 buzz |
| Lockdown_On | 封锁 | 金属门锁闭 + alarm |
| Comms_On | 通讯干扰 | 白噪声/static |
| EvidenceLeak_On | 证据泄露 | 数据损坏 glitch |
| PatrolAlert_On | 巡逻警报 | klaxon 重复脉冲 |

**环境 (3 事件)**
| Amb_Harbor | 港区 | 雨声 + 远处货船雾笛 |
| Amb_Police | 警署 | 室内空调 + 电话铃声 |
| Amb_Kowloon | 九龙城寨 | 巷道回声 + 麻将声 + 电扇 |

### 音频规格
- 格式：OGG Vorbis
- SFX：单声道 44.1kHz，< 200KB 每个
- 环境声：立体声 44.1kHz，< 2MB 每个
- BGM：立体声 44.1kHz，< 5MB（循环）

### 音量设置
- 主音量 (Master) 0-100%
- 音效 (SFX) 0-100%
- 环境 (Ambience) 0-100%
- 背景音乐 (BGM) 0-100%
- 存储：PlayerPrefs，启动时加载
- 静音：Master=0 等效于全局静音
