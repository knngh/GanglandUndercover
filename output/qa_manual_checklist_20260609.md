# Gangland Undercover — QA 手工测试清单

> 创建: 2026-06-09 | 版本: v0.2.0-dev
> 范围: 本地 Editor 单进程测试（Lobby + Relay 手工 QA 另见 `lobby_relay_qa_checklist_20260609.md`）

## 前提

- Unity Editor 已打开，Project 窗口选择 `Assets/_Project/Scenes/Prototype.unity`
- 测试从 Game 视图左上角 UI 面板操作（不是 Editor Hierarchy）
- 每次操作后检查 Console 窗口无红色 Error

---

## 1. Host 开房

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1.1 | 点击 ▶ Play | Game 视图显示主菜单面板 |
| 1.2 | 点击「创建 Host」按钮 | 状态栏显示"等待 Client 加入…" |
| 1.3 | 检查 Console | 无 NullReferenceException |
| 1.4 | 观察左侧玩家列表 | 显示 1 名玩家（自己） |

---

## 2. Relay 开房

| 步骤 | 操作 | 预期 |
|------|------|------|
| 2.1 | 回到主菜单（点击「离开房间」） | 回到初始界面 |
| 2.2 | 先关闭 Unity，重新打开 Project | 清理网络状态 |
| 2.3 | 点击「Relay 开房」 | 弹出 Relay 房间码（6位字母数字） |
| 2.4 | 记下房间码 | — |
| 2.5 | 检查 Console | 无错误 |

---

## 3. Relay 加入

| 步骤 | 操作 | 预期 |
|------|------|------|
| 3.1 | 打开第二个 Unity 实例（双开） | 第二个 Editor 启动 |
| 3.2 | 在第二个实例点击「Relay 加入」 | 弹出输入框 |
| 3.3 | 输入第 2.4 步的房间码 | 输入框接受输入 |
| 3.4 | 按 Enter 或确认 | 第二个玩家出现在 Host 的玩家列表 |
| 3.5 | 检查 Console（两端） | 两端均无错误 |

---

## 4. Ready 就绪

| 步骤 | 操作 | 预期 |
|------|------|------|
| 4.1 | 两端都点击「Ready」按钮 | 按钮变灰，显示"已就绪" |
| 4.2 | 检查 Host 端 | 显示 "N/2 已就绪" |
| 4.3 | 一端取消 Ready（再次点击） | 显示 "N/2 已就绪" 减少 |

---

## 5. Start 开始对局

| 步骤 | 操作 | 预期 |
|------|------|------|
| 5.1 | Host 端点击「开始」按钮 | 进入身份简报阶段 |
| 5.2 | 检查局面 | 两端都显示"身份简报"+倒计时 |
| 5.3 | 等待倒计时结束 | 进入 Action 阶段，地图显示 |
| 5.4 | 使用 WASD 移动 | 角色在地图上移动 |

---

## 6. Leave 离开房间

| 步骤 | 操作 | 预期 |
|------|------|------|
| 6.1 | 在对局中点击「离开房间」 | 弹出确认？(根据实现) |
| 6.2 | 确认离开 | 回到主菜单 |
| 6.3 | 检查 Host 端 | 玩家列表中该玩家移除（或显示断开） |
| 6.4 | 检查 Console | 无错误 |

---

## 7. Return Lobby 返回房间

| 步骤 | 操作 | 预期 |
|------|------|------|
| 7.1 | 在结算界面（Result）点击「返回房间」 | 回到 Lobby 准备界面 |
| 7.2 | 检查玩家列表 | 玩家显示就绪状态可重新设置 |
| 7.3 | 点击「开始」再次开局 | 新对局正常开始 |

---

## 8. 本地 Bot 局（单人测试）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 8.1 | 主菜单点击「补 AI 开局」 | 自动填满房间，Bot 加入 |
| 8.2 | 点击「开始」 | 进入身份简报 |
| 8.3 | 完整跑一局 | Lobby→Opening→Action→Meeting→Voting→Result |
